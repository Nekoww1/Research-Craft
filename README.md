# Research-Craft

将科研经验、方法论与原始案例组织成可系统学习、可随时查阅的交互式指南，帮助读者逐步形成独立做研究的判断与行动能力。

项目由个人长期学习与整理的需要出发，以公开仓库持续积累。前端是核心交付载体：通过合适的叙述、案例、对照、模板和图解，解释研究工作中的概念、取舍与具体做法。

## 本地阅读

直接用浏览器打开仓库根目录的 [index.html](index.html)，即可阅读正文与使用交互。也可以在仓库根目录运行：

```powershell
python -X utf8 -m http.server 4173 --bind 127.0.0.1
```

打开 [本地阅读页](http://127.0.0.1:4173/)。终端按 `Ctrl+C` 停止服务。网站不需要安装依赖或构建；字体、样式、图形与脚本均在本地，没有外部 CDN 请求。查看原始来源需联网。

## 当前状态

2026-10-20：首版已有四个教学基础模块：**选择值得投入的问题、让阅读改变问题、让证据回应主张、把研究写给读者**。它们尚未展开为完整课程大章，特别是领域调研与建立视野，当前只提供约 1100 汉字的基础讲解。具体作者、阅读范围、教学覆盖与缺口见 [内容进度](docs/CONTENT_STATUS.md)。

用户审阅后，界面已改为桌面横屏优先的按章阅读：20px 正文、横向案例与写作对照、当前章节的来源弹层和宽屏小节目录。首页明确标出基础稿与尚未成章的部分。没有增加新研究结果或将未读材料算入正文。

写作模块已进一步改成 **11 个独立页面、81 个教学小节，约 2.7 万汉字**。从 [写作总览](index.html#writing) 或 [摘要页](writing/abstract.html) 进入。内容包括全篇论证、标题、摘要、引言、方法、实验、图表、相关工作、讨论、结论、修改与语言。基于刘洋课件副本、官方整理与 Simon Peyton Jones 原课件，增加逐句分析、完整改写、可手算的贯穿例和练习。当前只深化写作，其他章节仍是基础稿。来源与教学分工见 [写作模块组织依据](docs/WRITING_STRUCTURE.md)。

19 条初始线索及后续案例的身份与阅读范围分别记录。本轮取得刘洋第三方课件副本，按写作主题选页视觉核对，并从其案例追到三篇新增原论文；不能冒称与原站版本完全一致或所有材料全文精读。用于核对的六份 PDF 保存在忽略目录，不随网站再分发。没有开展实验复现或真实读者效果评估。

网站使用静态 HTML/CSS/JavaScript，禁用脚本也能阅读；阅读不需要构建。写作正文在 `content/writing/` 维护，由标准库脚本生成可直接打开的 `writing/` 页面与搜索索引。GitHub Pages 尚未配置、未发布。

最窄静态检查：

```powershell
python -X utf8 scripts/build_writing.py --check
python -X utf8 scripts/verify_site.py
node --check assets/app.js
node --check assets/lesson.js
```

修改写作正文、页面目录或首页来源记录后，先运行 `python -X utf8 scripts/build_writing.py`，并将正文源与生成页面一起提交。`--check` 会发现未同步的交付文件，不会重写文件。

浏览器脚本使用验证环境中的 Playwright 与 Chrome；这是维护检查依赖，不是网站运行依赖。运行方式见 [验证记录](docs/VALIDATION.md)。

## 基本原则

- 根据概念和能力的逻辑组织完整正文，支持连贯阅读。
- 不同模块采用不同的教学方式：研究 taste 多用案例，写作多用模板与对照。
- 引导性问题在正文完成后酌情设计，并保持正文独立完整。
- 清楚区分作者观点、编辑综合、教学示例与个人实践。
- 在相关概念和案例附近提供原始来源，保留适用条件与重要分歧。
