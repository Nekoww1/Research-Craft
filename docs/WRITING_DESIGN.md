## 问题与方向

上一版把“更多彩”主要处理成浅色底、色条和功能色；不少实际承担标题职责的文字却是 12–16px 的普通小字。例如摘要开头对照的标题为 13px，正文为 18px。相同的容器反复出现，也没有充分表现稿件、分析、提示和练习之间的区别。

本轮以论文改稿与讲解为主线，保留紧凑正文，把设计投入到阅读顺序和模块内部结构。主要阅读环境是 1920、1536、1366 像素的桌面横屏。模块可以比连贯正文更宽，左右两侧必须能被实际比较。

## 视觉语言

基础颜色以蓝、墨色和冷白纸面为主：操作蓝 `#3158c9`、深蓝 `#243d61`、正文 `#202b3b`、次要文字 `#526176`、工作底色 `#f3f6fb`、分界线 `#dce3ee`。原有四种功能色只用于句子职责、局部修改和证据边界，减少整块填色和彩色标签。

正文沿用本地无衬线字体，中文为微软雅黑等系统回退；主要标题明确使用中文标题字体与粗字重，稿件中的 ABSTRACT 使用 Georgia。字号不靠不断放大正文建立层级：正文仍为 18px／1.8 倍行距、16px 段距；模块标题通常 20–24px／700 字重；旁批标题 18px、解释 16px；来源或上下文元信息为 13–15px。表头为 16px 粗体，不再小于数据文字。无需联网加载字体。

## 按教学用途设计模块

| 教学用途 | 当前呈现 | 设计承担的工作 |
| --- | --- | --- |
| 改写前后对照 | 同一改稿台中的两份稿件，明确的标题、分栏和修改理由 | 让目光横向比较同一信息，避免两个无联系的色块 |
| 摘要开头的完整示范 | 总标题 → 原稿／改写 → 含糊措辞／关键动作 → 两侧解释 → 改写抓手 | 把修改依据放到具体文本旁边；保留“教学示例”身份 |
| 真实摘要与案例分析 | 稿纸、连续阅读的原文释义、沿轨道排列的编号旁批 | 区分阅读材料与编辑解释；保留选择句子和键盘操作 |
| 引言完整修改 | 左侧草稿及诊断，右侧新的论证骨架 | 桌面直接对读，保留“研究计划、结果未取得”的边界 |
| 多轮修改 | 相连的阶段、较醒目的轮次与标题、底部修改理由 | 使先后关系可见，避免三张相同的彩色便签 |
| 自己动手 | 固定练习侧栏、任务正文、可展开的参考分析 | 一眼区分阅读材料和需要执行的动作 |
| MaxSim 算例 | 规则控件、相似度数据和独立结果区 | 让选择与结果对应；全部仍是人工教学数值 |
| 图与图注 | 白色图面、相邻的信息职责分析、逐轮补充的图注 | 图形与文字共同解释条件与边界 |
| 概念关系 | 轻量分隔的横向说明 | 降低无必要的卡片感，把注意力留给概念本身 |

不是所有内容都应做成复杂组件。精确比较仍用表格，解释条件仍用段落，来源仍在观点附近。没有加入滚动显现、自动播放或使正文默认隐藏的装饰性交互。

## 共同的学习入口

2026-10-21，用户反馈视觉略有改善，要求每个独立写作部分都有可立即学习的共性核心。本轮增加统一的页首入口，沿用已有颜色和字体。深蓝区承载本页核心判断，右侧三项要领解释可迁移的做法并链接到正文；下方呈现当场产出与掌握判断，再交代前后章节的职责连接和提炼依据。

这一结构统一学习的入口与使用方式；正文中的算例、案例、段落批注和图示继续按内容变化。目录置于核心之后，避免读者必须先扫完一串标题才能得到实质内容。核心始终可见，不依赖脚本、勾选进度或折叠操作。来源仍能就近打开。

方法与实验的核心在 1920、1536、1366 像素宽度并排展示判断与要领；较窄环境改为纵向，保持原始阅读顺序。结果段新增连续的四项信息职责与完整教学段落，既呈现写法，也保留条件。
