# 写作模块的结构、内容深度与来源分工

日期：2026-10-20，按用户“先把写作模块做细、各部分独立成页”修正。此前单页约 6000 汉字的结构稿未满足用户对信息量的要求；本轮取代该稿，不将旧稿记为已完成课程。

## 范围与编排决定

采用 **11 个独立静态页面、81 个教学小节，约 2.7 万汉字**。页数由写作任务决定：八个论文部分之外，增加全篇论证、图表、修改与语言。主线为全篇论证 → 各部分 → 跨节表达与修改。图表在实验之后教学，但实际应用贯穿各部分。

适用情境以计算机科学研究论文为主，讨论理论、资源和分析型贡献的调整。目录、篇幅与章序是编辑选择，不是投稿规范。用户当前要求仅深化写作；暂不把这一做法推广到其他大章。

## 内容深度的处理

不统一要求每页拥有相同模块。摘要重点是句子职责与压缩，方法重点是贯穿算例，实验重点是比较能支持什么，相关工作重点是关系，修改重点是诊断与执行。每页保留连续论述、具体例子、条件与练习；折叠仅用于参考分析，关键讲解默认可见。

共同的编写思路是：先弄清任务与概念关系，再用可追溯材料展开推理；通过改写、计算或比较显露判断过程；最后给出可执行的迁移练习。它是本轮编辑方法，尚未经真实读者试用验证，不能直接称为普遍有效的教学模式。

## 来源分歧与读取边界

- S019 为第三方托管的课件副本，封面已核，188 个文件页包含动画重复；与 S001 原站版本未对勘。中文提取异常，采用选页视觉核对。文件页与页脚同时标注，细表见 `READING_NOTES.md`。
- S009 通读可提取文字并选页视觉核对；S002 是官方整理，不冒记完整演讲课件。
- Jones 建议相关工作后置；真实 CVG 将相关工作置于 §2。正文解释两者条件，不强行合并成统一章序。
- Jones 对主动语态的偏好较强；编辑教学以动作和责任清楚为目标，不机械禁止所有被动句。
- 刘洋强调机器翻译实验中的显著性；编辑教学保留具体设计、统计单位和不确定性要求，不以一个阈值覆盖所有研究。
- 真实论文分析不补写动机和失败历史；自编文本、计划型段落、虚构结果设定和人工相似度均明确标注。

## 维护入口

正文唯一编辑位置：`content/writing/*.html`，页面目录信息在 `pages.json`。`scripts/build_writing.py` 用标准库生成 `writing/*.html` 与 `assets/writing-search.js`；生成结果一并提交，以支持本地文件阅读。`--check` 检测正文与交付页面是否同步。总览与来源入口维护在 `index.html`。
