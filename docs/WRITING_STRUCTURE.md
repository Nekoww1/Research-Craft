# 写作章的教学结构与来源分工

日期：2026-10-20。针对用户指出的“章节缺少结构”，本轮重构写作章，而不是只添加目录标题。

## 章级主线

全篇各部分的职责 → 贡献与证据的关系 → 各部分的具体写法 → 整篇修改。

适用情境：以方法和评估为主线的计算机科学论文。总览中的顺序是教学安排，不是固定投稿格式；理论、资源、综述等论文应按贡献类型调整。正文唯一维护在 `index.html#writing`，本文件只保存组织依据。

## 各部分怎样教、依据是什么

| 部分与锚点 | 教学重点与展示 | 原始依据／编辑边界 |
| --- | --- | --- |
| 全篇结构 `paper-map` | 八个可点击入口，说明各部分在同一论证中的职责 | S009 文件 pp.15–24 的叙述与结构；S002 的各部分讲解。总览为编辑组织 |
| 贡献与证据 `reader-first` | 同一贡献怎样跨越引言、方法、实验和结论 | S009 pp.21–24；S002 整体原则 |
| Title `paper-title` | 信息不足与更具体的自编标题对照 | 编辑补充，不冒称原作者的标题模板 |
| Abstract `abstract` | 四项信息职责；Forest Reranking 摘要的结构释义与旁批 | S002 摘要小节；S021 原论文摘要。释义不是原句翻译 |
| Introduction `introduction-logic` | 段落职责与贡献承诺；保留 `revision` 锚点的修改前后对照 | S002 引言小节；S009 pp.18–24。自编文本为假设研究计划 |
| Method `running-example` | 任务、见解、算法、训练与推断；ColBERT 信息流与公式解读 | S002 方法小节；S009 pp.36–39；S020 §3.1。图解不产生真实检索结果 |
| Experiments `experiments` | 主张与设置、结果、解释的对应表；真实论文实验结构分析；图表职责 | S002 实验小节；S009 p.24；S020 §4 开头 RQ 与后续结构。统计与不确定性不套统一口号 |
| Related Work `related-work` | 按比较轴组织关系；示例段落与旁批；位置取舍 | S002 相关工作；S009 pp.27–32。保留报告的后置建议，不当普遍规范 |
| Discussion / Limitations `discussion` | 观察、解释和边界的分层；具体局限的写法 | 编辑补充，S010 §3.1–3.2 支持解释强度的区分，不冒称两份主报告专门讲过本节 |
| Conclusion `conclusion` | 新增认识与边界；带条件的自编模板 | S009 p.16 仅提供整体结构位置，具体写法为编辑补充 |
| Revision `writing-action` | 跨节核对、读者反馈与修改顺序 | S009 pp.41–44；具体核对表为编辑方法 |

## 不能抹平的来源差异

Simon Peyton Jones 在报告中建议相关工作后置，以先建立对核心思想的理解。刘洋官方整理介绍相关工作的写法，没有规定必须采用该章序。讲座的建议、编辑组织与目标场合要求要分开判断。

S002 仍是官方整理文字，未取得完整演讲课件；S009 仍是局部文字阅读，未逐页视觉精读。Title、Discussion 和 Conclusion 的编辑补充不升级为原作者明确主张。

## 其余章节的处理

选题、阅读、证据三章增加了与现有正文对应的学习路径，并保留案例、阅读关系与证据对照各自的教学构造。这是结构显化，不代表它们已扩写成完整大章。
