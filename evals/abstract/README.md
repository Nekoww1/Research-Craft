# Abstract 任务对照

版本边界：之后的任务差异化更新已将默认选材改为起草8条／修改6条／审查7条，并支持补选指导。下方冻结的六份输入与原始输出没有覆盖这些新材料，也未重跑模型；请勿将旧输入量或质量观察直接当作当前版本结果。

这里验证按任务组织的知识能否支持实际写作。现有教学全文与结构化材料使用相同任务契约、同一份 [ColBERT 受限事实包](research-input.json)，分别完成起草、修改和审查。错误草稿是本站教学构造；论文事实与口径经原文复核，见 [审计记录](../../docs/ABSTRACT_AI_AUDIT.md)。

已执行的 [2026-10-21 探索性对照](run-2026-10-21/REPORT.md)保留六份完整提示与六份原始答复。每个样本为独立子代理会话，未共享当前聊天历史，沿用当前模型；不得把它描述为独立 API、盲评或统计有效的效果验证。

准备新一轮时指定新的仓库内目录：

```powershell
python -X utf8 scripts/prepare_abstract_eval.py --run-dir evals/abstract/run-new-name
```

脚本只冻结输入并计算规模，不运行模型；目录已存在会拒绝覆盖。标准库可准备文本，安装 `tiktoken` 时另给 `o200k_base` 的参考分词数。按样本开启不带历史的独立会话，只给相应提示，将原始答复存到 `responses/` 后再分析。不要改掉失败答复、覆盖旧提示或用重试挑选理想结果。

共同判断围绕事实、机制、比较口径、结论范围及任务是否完成。规则编号只帮助追溯，不作为两条件的共同质量得分；整章条件没有相同编号。真实事实包已给出许多边界判断，当前试验不能说明模型会自行发现未知论文中的问题。
