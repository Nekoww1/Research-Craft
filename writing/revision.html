论文写作 / 11 / Revision & language

把草稿改成读者能够理解的论文

先修论证，再修段落和句子；把读者反馈变成可执行的修改。

本页重点

进行逆向提纲、跨节核对、长句拆分、动词修改与有条件的英语表达练习。

1. 先修论证，再修表达2. 用逆向提纲发现结构断点3. 把读者反馈转换成具体修改4. 用主语和动词显露动作5. 拆长句时，保留逻辑关系6. 让词语承担准确的证据强度7. 局部英语与引用：理解规则，再使用模板8. 学习句式时，也学习它完成的动作9. 一次有次序的修改练习

1. 先修论证，再修表达

如果引言承诺检验机制，实验却只比较平均分，改进语法不会修复证据缺口。如果方法步骤缺失，换一个更精致的图例也无法让人复核。修改应先判断问题发生在哪个层级，再选择动作。

Jones 将写作视为形成思想的机制，并强调认真听取读者在哪里失去理解；刘洋建议由粗到细、多轮修改，并借助不同背景读者发现信息壁垒。这里把这些建议落实为修改次序，而不把课件的具体日程当作所有人的统一时间表。文件 pp.4–7、41–44文件 p.185／页脚 85

论证主张、证据、范围是否一致
结构读者是否在需要时得到信息
段落中心与支撑是否相称
句子动作、指代、条件是否清楚

不必先把某一层修到完美才进入下一层。局部文字问题可能暴露概念不清；结构修改也可能要求重新安排实验。但在决定大幅重写之前，应先知道它准备解决哪个真实阅读或论证问题。

2. 用逆向提纲发现结构断点

完成一版草稿后，不看自己原定的提纲，为每段写一句实际中心，再把这些句子连起来。这叫逆向提纲，是本页采用的编辑方法。它能让“原本想写什么”与“实际让读者读到什么”分开。

一份假设引言的逆向提纲
实际段落中心发现的问题修改动作
领域很重要。尚未限定本文的问题。用具体任务或限制缩小入口。
方法 A 很流行。没有说明 A 已有能力与剩余困难。补与贡献有关的比较。
我们增加模块 B。B 与前面的困难没有连接。说明设计理由，或重新选择主线。
我们进行了很多实验。读者无法预测证据职责。改成检验哪些具体主张。

如果几段实际都在表达同一件事，可以合并或让其中一段承担新的职责。如果相邻中心之间需要读者自己补很长的推理，就应补解释或调整顺序。若段落已经清楚，不必为了凑“中心—支撑—衔接”外形重写。

再做跨节对读：摘要中的每项结果是否在正文，贡献是否被方法与证据接住，结论是否收束同一个对象。研究中途改变方向时，这一步尤其重要，因为旧承诺常残留在最先写出的摘要与引言里。

3. 把读者反馈转换成具体修改

专家可以发现文献、假设和技术比较的问题；相邻领域读者可以暴露背景缺失、术语障碍和跳步。Jones 强调首次阅读机会只有一次，应明确请读者指出在哪里迷失，而不只寻找拼写错误。文件 pp.41–44

可以给读者一项明确任务：“只读引言，复述问题和贡献”“看方法图，解释输入怎样成为输出”“看表 2 和图注，说明什么比较支持哪项主张”。这比笼统问“写得好吗”更容易获得可用反馈。

从反馈定位缺失信息 · 教学示例
读者反馈可能原因先检查
不知道为什么需要模块 B。设计理由缺失，或 B 并非主论证所需。困难、动作与目标的连接。
以为这里只改了训练数据。方法区别被数据说明淹没。核心改变是否明确、图与文字是否一致。
把 oracle 当成实际质量。指标定义不足。结果附近和图注是否解释“可达到”与“实际取得”。
认为结果能覆盖所有领域。对象和条件在压缩时丢失。摘要、结论和讨论中的范围词。

反馈是定位线索，不是必须照做的命令。若建议引入新的错误，应保留原研究事实，并寻找更清楚的解释。不要通过口头补充证明读者“本来应该懂”；若重要信息只在解释时出现，应考虑将它写回论文。

4. 用主语和动词显露动作

Jones 的语言页强烈倡导主动语态与直接表达；刘洋课件也给出被动句、弱动词和结构松散的改写。实际应用时，重点是动作和责任清楚，而不是禁止所有被动句。测量对象比执行者更重要时，被动表达仍可能自然。文件 pp.50–51文件 pp.141–146／页脚 70–71

教学草稿

An improvement in retrieval quality was obtained through the utilization of an additional matching stage.

改善、使用和阶段都被名词化，读者要自己寻找动作。

教学改写

Adding a matching stage improved retrieval quality in our evaluation.

动作与观察直接相连；仍需在邻近位置给出评价条件和结果。

这句改写只适用于已经取得相应观察的场合。若只是设计目标，应写成计划或目的，不能因为主动语态读起来更有力，就把尚未成立的效果写成事实。语法强度和证据强度需要同时检查。

另外，指标本身通常不会“性能提高”。可以说模型的翻译质量按 BLEU 衡量有所变化，而不是让“BLEU 的性能”代替研究对象。刘洋课件的修改例涉及类似语义错位；学习时应理解为什么换主语，而不是记住一组替换词。

5. 拆长句时，保留逻辑关系

长句的问题不只在字数。多个背景条件、执行者和结果挤在一起，会使读者无法判断谁做什么，以及因果、转折、目的分别在哪里。刘洋用机构参与语料建设的句子展示拆分：先概括主要事件，再单列参与者。文件 p.140／页脚 69

教学草稿

To reduce the cost of repeated document encoding, which becomes substantial when many queries use the same collection, we store token representations before evaluation and then use a matching stage that compares each query token with the stored document tokens.

教学改写

Repeated document encoding is costly when many queries share a collection. We therefore store document token representations before evaluation. At query time, a matching stage compares each query token with the stored document tokens.

三句分别交代条件下的问题、相应计算安排和查询时操作。不是简单在逗号处切开：第二句保留“因此”的关系，第三句明确时间阶段。如果实际没有成本测量，第一句的 “costly” 还需要依据或更克制的描述。

拆分后也要检查重复。若每句都重新介绍“我们的方法”，可能需要用明确指代；如果代词 “it” 可能指模型、索引或分数，应重复关键名词。清楚优先于机械避免重复。

6. 让词语承担准确的证据强度

“show”“suggest”“prove”“explain”不应只按风格替换。它们涉及不同类型的主张：观察结果支持到哪里，是否有形式证明，是否区分了竞争解释。不存在一张脱离上下文的万能动词强度表，但每次使用强动词都应能说明依据。

语言修改要同时检查研究含义 · 编辑示例
草稿用词需要问可能的修改
significantly better有统计检验，还是只是差值看起来大？报告实际差异与分析；未检验时不暗示统计结论。
proves the mechanism是否真的排除了其他解释？若只有相容观察，说明支持哪种解释及未排除项。
robust across tasks跨了哪些任务与变化？写明实际覆盖对象和条件。
negligible cost对哪种预算与使用条件可忽略？给出成本，并说明比较口径。

还要检查时态是否帮助区分一般定义、本文已经完成的动作和未来计划。具体惯例由场合决定，但不能将尚未运行的评估写成过去时结果。最后检查同一概念是否始终使用相同名称，避免“表示、特征、嵌入”在没有定义区别时轮流替换。

7. 局部英语与引用：理解规则，再使用模板

刘洋课件用 a／an 说明发音比首字母更重要，用 the 说明特指与泛指的区别。这些例子提醒作者检查表达条件，不能把一条简化规则套到所有名词短语。文件 pp.147–157／页脚 72–73

例如，按常见字母读法可写 an SVM，而 a European dataset 的 European 以辅音音素起始。the 则常用于读者可识别的特定对象：a model 引入一个模型，随后 the model 指回该模型。领域术语、不可数名词和固定表达仍需结合上下文核实。

引用句也需要语法完整。作者作为主语时，写清谁提出、分析或证明了什么；括号引文则为已经完整的句子提供来源。引用格式可以由工具生成，但“这份来源是否支持这句话”仍须人工核对。文件 p.159／页脚 75

公式后的文字若继续同一句，应按语义和目标排版规范处理标点、缩进与大小写；若开始新段，明确开启新的论述。刘洋课件以公式后的说明展示这一细节。它不是通过视觉距离判断句子是否结束，而是让语法和版面共同表达关系。文件 p.158／页脚 74

8. 学习句式时，也学习它完成的动作

课件建议从优秀论文中记录句式和词汇用法，并通过检索核对搭配。迁移时应同时记录句式的功能：提出问题、限定条件、比较方法、报告观察或保留解释。只保存华丽连接词，容易得到语法流畅但论证空洞的句子。文件 pp.161–175／页脚 77–79

把句式变成有条件的写作工具 · 以下为自编模板
功能句式骨架填写前提
明确比较Unlike X, our method changes Y while retaining Z.X、Y、Z 的关系已经核实。
报告结果Under C, we observe X relative to baseline B.C、B 与观察有明确位置。
保留解释This observation is consistent with H, but does not distinguish it from A.能解释为何相容，以及 A 是什么。
指出边界We have not evaluated C; the present results therefore do not establish P.C 与 P 的缺口确实影响判断。

检索命中数不能证明搭配正确。需要打开可靠上下文，看词义、学科、语法角色是否一致。课件中的历史搜索数字只是演示，不应成为今天的证据。使用生成式工具也同理：可以比较改写，但要复查是否丢掉条件、改变数据或增强了因果措辞。

9. 一次有次序的修改练习

选一份已经有正文的草稿，完成三轮不同任务

  1. 论证轮：只读标题、摘要、引言贡献和结论，标出对象、证据与范围冲突；需要研究补充的地方单列。
  2. 理解轮：做逆向提纲，走一遍方法算例，检查图注与结果解释；请读者指出首次迷失位置。
  3. 表达轮：改主语、动词和长句，统一术语，核对数字、引用、格式与目标场合要求。
怎样判断这一轮是否有效

比较修改前后读者能否完成同一任务：复述贡献、走通步骤、解释结果。若只增加了字数和形容词，没有解决原先的问题，就应回看诊断。真实读者效果需要实际试读；当前本站仅提供方法与教学练习，不声称已经完成读者实验。

修改结束后保留一份简短记录：改了哪项主张、补了哪条依据、解决哪个阅读断点、还有什么未决。它既能帮助合作者审阅，也能避免下一轮把已收窄的结论重新写宽。
